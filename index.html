Las fechas de compromiso vacías quedan pendientes de acordar. “Por aclarar” identifica datos de la minuta que necesitan validación. Los avisos de vencimiento se calculan respecto de la fecha local de hoy.

Cómo usar y conservar las minutas
  1. Capture acuerdos con responsable, compromiso y estado. Puede editar o cerrar cada fila.
  2. Descargue un respaldo al terminar. El guardado del navegador es local: no se comparte ni sustituye el respaldo.
  3. “Siguiente reunión” conserva la reunión anterior y copia los pendientes, sin los cerrados ni cancelados. Revise las fechas de compromiso.
  4. “Guardar HTML con datos” crea un archivo autónomo con todas las reuniones para trasladarlo a otro equipo.
  5. “Imprimir / PDF” incluye la minuta completa, aunque haya filtros. En el diálogo del navegador elija Guardar como PDF.
  6. Comparta el respaldo JSON o el HTML con datos para actualizar el seguimiento. Este archivo no ofrece edición simultánea entre equipos.
